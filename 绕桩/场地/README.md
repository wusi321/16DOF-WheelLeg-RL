## 1. 这是什么场地

机器人要走一条 **L 形**路线，绕开排列成 L 形的 6 根竖桩，中途必须踩到 3 个圆形必达区。

**官方规格（《2027 年足式机器人挑战赛 V1.0》表 1）原文**：

> 竖桩布局为 L 形。每个竖桩的直径为 100mm、高度为 100mm，竖桩之间的中心距 900mm。
> 绕桩区的两端及拐角外侧各有一个圆形必达区（红色虚线圆），直径为 300mm。竖桩颜色为绿色。

| 项目 | 规格 | 说明 |
|---|---|---|
| 竖桩 | **圆柱，直径 100 mm、高 100 mm** | 只有 10 cm 高，轮子能压过去——难点是"绕过"不是"跨越" |
| 布局 | **L 形，6 根** | 水平臂 4 根（含拐角）+ 竖直臂额外 2 根 |
| 柱距 | **固定 900 mm** | 官方固定值，不随难度变化 |
| 必达区 | **3 个，直径 300 mm 红色圆** | 水平端外侧、拐角外侧、竖直端外侧 |
| 必须顺序 | **水平端 → 拐角 → 竖直端** | 不能跳着走 |
| 赛道 | 6.0 × 3.0 m（L 形需要更大空间） | 平地 |
| 回合 | 30 秒 | |

> **2026-11-28 修正**：这一版之前把规格建错了——做成了 50×50×300 mm 方柱、一字直线排列、
> 柱距 1.00→0.52 m 递减、每根柱旁放一个必经点。对着官方规则和 `Robocon2027.xml`
> 核对后，全部改成上面的官方规格。旧版的蓝色小方块数量多，是因为"每根柱旁一个"，
> 而规则里真正的判定点只有 3 个。

地形里会放两类辅助几何体，判据按**几何签名**把它们读出来，所以训练代码不需要知道
当前难度是多少、也不用和地形参数对齐：

- 每个必达区放一个「不碰撞 + 极薄 + 截面半宽正好 0.02」的小方块 → 判据认它是必经点
- 视觉上的红色薄圆盘（半径 0.15）尺寸不同，既不会被认成必经点，也不会被认成柱子

## 3. 判据怎么设计的（`src/robot/mdp/slalom.py`）

| 判据 | 作用 | 说明 |
|---|---|---|
| `waypoint_reward` | 每按顺序经过 1 个必达区给 +5 | 只有 3 个，走完就满分 |
| `all_waypoints` | 3 个全走完额外 +30 | 一次性奖励 |
| `skip_penalty` | **跳过**必达区重罚 −30 | 防止抄近路直接奔最后一个 |
| `pillar_hit` | 蹭到柱子扣 −5 | 6 根柱子都算 |
| `slalom_progress` | 已通过 / 3 | 直接看这个判断"走了几个点" |

**两个容易踩的实现细节（2026-11-28 修过）**：

1. **顺序必须按"离起点的距离"排，不能按 x 排**。
   因为是 L 形，拐角外侧的必达区 x 比竖直端的更大，按 x 排会把竖直端排到拐角前面，
   顺序就错成 A→B→C。现在改成按到 origin（起点）的距离排序，结果是 A→C→B，正确。
2. **柱子识别要区分圆柱和方柱**。官方柱子是**圆柱**，MuJoCo 里圆柱的"半高"存在
   `size[1]`、方柱存在 `size[2]`。只认 `size[2]` 的老写法会让圆柱柱子一个都识别不到
   （实测 PILLARS=0，等于撞柱不扣分）。

## 4. 第一次训练要注意什么

因为**还没人训过**，以下是预判的风险点，训的时候重点看：

1. **可能学成"直线冲"**。如果 20~30 轮后发现它只吃第一个必达区、`slalom_progress`
   一直不动，说明它没学会转向。注意 L 形后半段必须往 y 方向拐。
2. **桩只有 10cm 高，可能被"压过去"**。轮子直径 10.8cm，理论上能骑上 10cm 的桩。
   如果发现它直接碾过柱子而不是绕开，说明 `pillar_hit` 的扣分太轻（现在 −5），
   需要加重。这也是"绕过 vs 跨越"的判定关键。
3. **转弯能力**是核心。这个场地真正考的是横向移动和转向，如果机器人
   压根不会横着走，先在 `站立行走转弯` 那个项目里把基础能力练出来再回来。
4. **判据没经过实战检验**。梅花桩的判据调了十轮才发现"惩罚过重会逃避"这类问题，
   绕桩的判据还没被这么打磨过，出怪现象是正常的。
