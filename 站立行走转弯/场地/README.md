## 3. 推荐训练顺序（重要）

**不要跳步**。这四个任务是层层递进的，跳过去训后面的大概率白训：

```
Stand（站住不抖）
  ↓ 站稳了再往下
Flat（平地上走）
  ↓ 走顺了再往下
Rough（台阶、墙、乱石混着走）
  ↓ 能在粗糙地形走了再往下
专项障碍（高墙 / 低杠 / 跨沟 / 绕桩 / 梅花桩）
```

原因很实在：**梅花桩那边用血泪验证过**——如果基础步态没练好就直接上专项障碍，
策略会发展出各种歪招（原地蹭、摔倒逃避、只吃容易的分），而且练坏了很难纠回来。

## 4. 怎么训练

四个任务的命令格式完全一样，只是任务名不同：

```powershell
$root="D:\Project\nano\16dof-rl"; $py="D:\Project\wheelleg-rl\.venv\Scripts\python.exe"
$env:PYTHONPATH="$root\src;$root\mjlab\src"; $env:PYTHONIOENCODING="utf-8"
$env:WARP_CACHE_PATH="$root\.cache\warp"; $env:TMP="D:\Project\nano\.tmp"; $env:TEMP=$env:TMP
Set-Location $root

# 例：练平地行走
& $py -u train_16dof.py Robot-16DOF-Flat-v0 --agent.max-iterations 1200 --agent.run-name "flat_第一轮"

# 例：练粗糙地形
& $py -u train_16dof.py Robot-16DOF-Rough-v0 --agent.max-iterations 1200 --agent.run-name "rough_第一轮"
```

回放看效果（所有任务通用）：

```powershell
& $py play_16dof.py <任务名> --agent trained --num-envs 1 --viewer viser `
    --checkpoint-file "<模型路径>.pt"
```

## 5. 各任务的关键设计（改之前先看）

### Stand（站立）
- **速度指令全部设为 0**，机器人没有"走"的目标，只要求站稳
- 关掉所有移动类奖励，只留姿态、高度、平滑、力矩惩罚
- 回合只有 10 秒（站住 500 步就算成功）
- 摔倒惩罚极高（`is_terminated` 权重 −200），所以安全第一

### Flat（平地）
- 最基础的行走任务，指令范围正常
- 如果这个练不好，不要往下进行

### Rough（粗糙地形）
- 7 种地形按比例混合：平地 15%、倒金字塔台阶 35%、随机网格 27%、
  正金字塔台阶 5%、高墙 15%、随机噪声 1%、斜坡 1%
- **课程释放机制**：一开始只放简单地形，练到一定轮数后才逐个放出难的
  （随机网格 200 轮后、倒金字塔 500 轮后、高墙 700 轮后）
- 所以这个任务前期很快、后期会卡一下，是正常的

### Crawl（爬行）
- 低姿态移动，含低杠地形
- 如果专门想练低杠，用 `Robot-16DOF-LowBar-v0`（2026-11-28 新拆出来的独立任务）

## 6. 和比赛的关系

比赛现场是要"从起点一路跑到终点"的，中间连续多个障碍。所以：

1. 基础能力（这个项目）是所有专项的地基
2. 各专项场地单独练精
3. 最后需要一个**综合赛道**任务把它们串起来（对应 `其他` 里的「组合 Combo」，
   但目前组合只串了跨沟和绕桩，还不足以覆盖全部障碍）
