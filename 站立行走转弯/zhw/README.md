## 已知问题

转向偏弱（yaw 误差 0.434）。根因二则，均已修复，但**本权重不含**，重训后差别明显：

1. `naming.WHEEL_SIDE_SIGNS` 原为 `(1,-1,1,-1)`，按 (FR,FL,RL,RR) 排是 FR 配 RL 的**对角配对**，
   四个轮子的偏航力矩互相抵消——实测原地转 yaw≈0，`wheel_roll_tracking` 一直在奖励一个
   转不动车的轮速组合。已改为 `(1,-1,-1,1)`（右 +1 / 左 -1）。
2. 轮速执行器 kv=1 太软（轮子打滑时只出 2.2 N·m，5 N·m 上限用不满），已改为 10；
   轮子力矩上限按 RobStride 02（额定 6 / 峰值 17 N·m）改为 12 N·m。

第 3 版还会放宽 `leg_joint_vel`（−1e-3 → −2e-4）、加强 `track_ang_vel`，并把 yaw 指令范围放宽到 ±1.5。

## 注意

如果想使用本权重，并且希望机器在**无指令输入**时保持稳定，记得加上**强制归零**的指令，也就是让机器回到初始动作（零点姿态）。
