## 1. 这是什么场地

一个 **L 形**的浅坑，四周有 150mm 高的护栏，坑里灌满了碎砖头和腐熟的松树皮。
机器人必须从**短边**跨过护栏进坑，在松散材料里走完 L 形，再从**另一个短边**出来。

**官方规格（表 1）原文**：

> 砖木坑 2000mm × 2000mm。L 形砖木坑的护栏内分两个区，两侧分别填有碎砖头、
> 腐熟松树皮（10-20mm）。短边宽 1000mm，长边长 2000mm。护栏高度为 150mm，颜色为绿色。

**通过判定（表 2）原文**：

> 机器人必须从砖木坑的**短边**进入或离开。跨越过程中，若机器人足数的 1/2 以上
> 足端（含 1/2）与**坑外地面**接触，则越障失败。

| 项目 | 规格 |
|---|---|
| 整体外接 | **2000 × 2000 mm** |
| L 形臂宽（短边） | **1000 mm** |
| 长边 | **2000 mm** |
| 护栏高度 | **150 mm** |
| 护栏颜色 | 绿色 |
| 坑内填充 | 碎砖头 + 腐熟松树皮（粒径 10–20mm），分两区 |
| 进/出口 | **只能走短边** |

## 2. L 形是这么摆的

```
   y ↑
     │   ┌──────┐
     │   │ 碎砖区│              ← 横臂（在 +x 端，短边开口朝右）
     │   │      │
     │   └──┬───┘
     │ ┌────┴───┐
     │ │  树皮区 │              ← 竖臂（短边开口朝下）
     │ │        │
     │ └────────┘
     └──────────────────→ x
```

- **竖臂**：宽 1000（x 向）× 长 2000（y 向），短边开口在 **y 最小**那一侧
- **横臂**：长 1000（x 向）× 宽 1000（y 向），短边开口在 **x 最大**那一侧
- 两个区由一道 **45° 斜护栏**分开（官方模型里有这道 `pit_separator`）

机器人路径：**从右边（+x）短边进坑 → 拐角 → 沿竖臂往下 → 从下面（−y）短边出坑**。

## 3. 这个场地为什么难

1. **材料是散的**。碎砖和树皮会滑、会陷，轮子在上面抓不住地 —— 这是 8 个障碍里
   唯一一个"地面本身不稳定"的。
2. **只有 150mm 的护栏要跨**。看似不高，但跨过去之后立刻踩在松料上，很容易陷下去。
3. **不能出坑**。规则说 1/2 以上足在坑外地面就算失败，所以不能"在坑边走"，
   必须整个身子进到坑里。
4. **走的是 L 形**。进去之后要拐 90°，比直着走难得多。

## 5. 实现说明（重要，别被"仿真出来的样子"误导）

MuJoCo 里**没法真的模拟颗粒流**。真正的碎砖/树皮会塌陷、会侧向流动，仿真做不到。

这里的做法是：在坑内铺一层**随机大小的小方块**（边长 45mm，高度 40~80mm 随机），
摩擦系数设成 **0.45**（硬地面是 0.8），近似"踩上去会滑、会陷"的感觉。

**这只能是近似。** 具体缺什么：

| 真实情况 | 仿真是怎么样的 |
|---|---|
| 材料会塌、会侧向流 | 小方块固定在原地，踩了只会滑，不会"陷进去" |
| 材料高度会随踩踏变化 | 高度固定不变 |
| 轮子会陷进材料里 | 轮子压在小方块顶上，最多滑一下 |

**所以训练出来的策略，到了实场大概率需要重新适应。**
如果发现机器人在坑里打滑到完全走不动，优先调 `fill_friction`（调高到 0.55~0.6），
而不是加奖励、加惩罚 —— 那是治标。

## 6. 判据现状（**这里也有没做完的地方**）

官方两条硬要求：
1. 必须从**短边**进或出
2. **1/2 以上足在坑外地面** = 失败

**现在这两条都还没写进判据。** 当前用的是通用判据（前进 + 到终点 + 摔倒终止）。

也就是说：现在训练出来的策略，可能会从长边跨进去、或者在坑边"贴着走"，
那些动作在实场都是要被判失败的。

要补的话，需要写一个 `mdp/brick_pit.py`，记录：
- 四个边界里哪两个是"短边"
- 每一步有几只足在坑外地面

**建议先用现在的版本训练，看能不能在坑里走起来**，能走了再收紧判据。
