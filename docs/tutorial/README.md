# 教程：从零调通一个轮足强化学习任务

真实配置代码和三次训练数据为素材，讲清楚"怎么设计一个 RL 任务"和"怎么用 wandb
看出训练到底出了什么问题"。

## 素材：三次训练

所有截图在 [`assets/images/`](../../assets/images/)，回放视频在
[`assets/videos/`](../../assets/videos/)，完整的曲线解读在
[`docs/TRAINING.md`](../TRAINING.md)。

| 轮次 | 运行目录 | 配置要点 | 结果（也是最好的反面教材） |
| --- | --- | --- | --- |
| 第 1 轮 | `2026-10-26_22-26-00` | 40960 环境、patch 4 m、终点奖励与覆盖率无关 | 课程全通，但**靠滞空飞越**，覆盖率 0.43、回合 58 步 |
| 第 2 轮 | `2026-10-27_07-56-35` | 加了覆盖率打折 + 滞空/超速惩罚 | 覆盖率爬到 0.85，但末期**趴在桩上磨时间**（回合顶到 900 步超时） |
| 第 3 轮 | `2026-10-28_10-23-47` | 20480 环境、patch 8 m、回合 30 s、奖励重平衡 | **首次稳定通过**；但覆盖率卡在 0.50（只走一条桩列），600 迭代后姿态开始退化 |

三个坑对应的三次修复：`c64bb45`（反飞越）、`6843e16`（反摆烂）、`efc378c`（单桩交错）。

## 一句话总结这套方法

> **先保证"能过去"，再保证"按规则过去"，最后才谈"过得漂亮"。**
> 每一层都要有一项**独立的验收指标**，否则会像本项目前两轮那样，
> 奖励一路涨、任务一路崩。
