## 1. 这是什么场地

**L 形**组合障碍：台阶 → 平台 → 一条 36cm 的沟 → 平台 → 20° 斜坡。
这是全部 8 个障碍里**分值最高**的一个（自动 300 分），也是唯一需要"跨"的。

**官方规格（表 1）原文**：

> 沟壑组合障碍呈 L 形，两顶部平台高度均为 360mm，长宽均为 800mm。
> 斜坡侧平台为启动区 2，刷有黄色水性漆，外围是红色虚线。
> 台阶深度 320mm、高度 120mm，宽度 800mm。
> 沟壑为两顶部平台之间的间隔，宽度为 360mm。斜坡坡度为 20 度。

**通过判定（表 2）原文**：

> 机器人可从任一方向迈上台阶/斜坡，通过沟壑后，从另一方向的斜坡/台阶回到地面。
> 机器人在通过台阶时，要求**至少每一级台阶顶面与机器人足底有一次接触**。
> 跨越过程中，若机器人足数的 1/2 以上足与地面接触（含 1/2），则越障失败。

| 项目 | 规格 |
|---|---|
| 平台高度 | **360 mm** × 2 个 |
| 平台尺寸 | **800 × 800 mm** |
| 台阶 | 深 **320 mm**、高 **120 mm**、宽 **800 mm**（2 级） |
| 沟壑宽度 | **360 mm** |
| 斜坡坡度 | **20°** |
| 形状 | **L 形**（台阶/沟在 x 向，斜坡拐到 y 向） |
| 启动区 2 | 斜坡侧平台上（黄色 + 红色虚线） |

**得分**：上台阶 75 + 下台阶 75 + 跨越沟壑 150 = **最高 300 分**。

## 2. "L 形"是怎么回事（很多人理解错）

不是"两块平台摆成 L 形"，而是：

```
        ┌──────────── 斜坡（20°，朝 +y 方向下到地面）
        │
   [平台B]  ← 启动区2
      │
   [ 沟 ]  ← 360mm
      │
   [平台A]
      │
   [台阶2]  ← 顶 240mm
      │
   [台阶1]  ← 顶 120mm
      │
   地面（进/出口）
```

**台阶-平台-沟-平台这一串是直的（沿 x 方向），但出口斜坡拐了 90°，沿 y 方向下去**
—— 这就是"L 形"的由来。

## 6. 这个场地难在哪

1. **36cm 的沟是硬坎**。轮腿机器人轮径 108mm，沟宽是轮径的 3.3 倍，
   不可能"滚过去"，必须**跳过去**或者**伸腿搭到对岸**。
2. **平台高 36cm**。上去要爬两级台阶（12→24→36cm），下来要控制住别砸。
3. **规则要求"每级台阶顶面至少接触一次"**。意味着不能一步跨两级台阶，
   必须一级一级踩。训练时不加这个约束的话，学出来的动作在实场会判失败。
4. **1/2 以上足着地 = 失败**。不能"掉下去再爬上来"，一次成型。

官方要求"每级台阶顶面至少与足底接触一次"，但**当前判据里还没有这条**。

到了实场会被判失败。**
