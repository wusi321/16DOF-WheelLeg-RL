## 1. 这是什么场地

平地上摆着 8 个**平放的轮胎**，机器人要踩在轮胎的**环形胎面**上走过去。

| 项目 | 规格 | 出处 |
|---|---|---|
| 轮胎外径 | **0.55 m** | 官方规则表 1："外径约 550mm"（165/70R13） |
| 轮胎内孔直径 | **0.33 m** | 官方规则表 1："内径约 330mm" |
| 轮胎高度（胎面宽） | 0.165 m | 官方规则表 1：165/70R13 的胎面宽度 165mm |
| 阵列 | 4 × 2 共 8 个 | 官方模型 |
| 中心距 | 0.56 m（横纵相同，即彼此相切） | 官方 `Robocon2027.xml` 实测 |
| 赛道 | 8.0 × 1.6 m，目标 6.8 m | |

**这个场地和别的都不一样**：难点不在"跨过去"，而在**踩得住多窄**。
胎面是宽仅 **0.11 m** 的窄环，环中间是深 0.165 m 的孔。
轮子必须正好落在环上，偏一点就陷进孔里。

---

## 2. 碰撞体是怎么做的（重要）

官方模型里**没有用环形网格做碰撞**，而是用 **12 个小圆柱围成一个环**：

- 小圆柱：半径 0.055 m、高 0.165 m
- 摆在半径 **0.22 m** 的圆上，12 个均匀分布
- 这样外缘 0.275、内缘 0.165，正好贴合轮胎轮廓（外径 550mm、内径 330mm）

代码完全照这个做法生成（`terrains/tire_array.py`），所以训练时的碰撞行为和实车一致。
8 个轮胎 × 12 个圆柱 = 96 个碰撞体，加上地面一共 97 个几何体。

> **2026-11-28 修正**：旧版用的是外径 0.56 / 内孔 0.34，那是从官方模型碰撞体
> 反推出来的（12 个半径 0.055 的圆柱摆在半径 0.235 的环上，外缘 0.29 = 直径 580mm），
> 比规则值大 5%。
> 现在改成**规则值 0.55 / 0.33**：比赛场地是按规则尺寸做的（规则第 7 条允许 ±5% 误差），
> 训练贴近规则值更稳妥。同时中心距 0.56 保持不动——那是模型里实测的轮胎摆放间距。

## 4. 课程难度怎么设计

**靠轮胎高度从 0.06 m 长到 0.165 m**：

| 难度 | 轮胎高度 | 会发生什么 |
|---|---|---|
| 0 | 6 cm | 轮子直径 10.8 cm，能直接滚上去，约等于平地 |
| 中 | 9~15 cm | 开始需要抬腿踩上胎面 |
| 1 | 16.5 cm | 实场难度，必须精确踩在 0.11 m 宽的窄环上 |

先低后高是刻意的：一上来就 16.5 cm，轮子爬不上去，只会反复撞轮胎。

---

## 5. 判据为什么只写"前进 + 到终点"

和低杠、高墙的理由一样：**物理约束本身就是最好的老师**。

踩偏了会真的掉进轮胎中间的孔（深 16.5 cm），卡住走不动、前进奖励自然就没有了。
再加一个"落点在胎面上就给分"的奖励不但多余，还容易引发梅花桩那边踩过的坑——
奖励设计太复杂，策略会学会钻空子而不是真本事。

## 6. 第一次训练要盯什么

1. **可能学成"从两个轮胎中间穿过去"**。轮胎之间是相切的（间距 = 外径），理论上
   没有缝，但如果它学会用轮子卡在接缝处蹭过去，就说明难度不够，需要抬高轮胎。
2. **可能卡在某个等级**。`Curriculum/terrain_levels` 涨到某级不动了，说明那级轮胎
   太高踩不上，需要调低 `height_range` 上限。
3. **和梅花桩的相通之处**：两者都要求"踩准一个窄面"。如果梅花桩已经练好了落点，
   这个可能上手较快，可以试试从梅花桩模型接着训（但要接受落点指标可能变差）。

**集成方法**（三处都要改，缺一个就跑不起来）：

1. `tire_array.py` 复制到 `src/robot/terrains/`
2. `src/robot/terrains/__init__.py` 里加导出：
   ```python
   from .tire_array import BoxTireArrayTerrainCfg
   # 并加进 __all__ 列表
   ```
3. `env_cfgs.py` 顶部 import 加 `BoxTireArrayTerrainCfg`，再粘入 `env_cfg_tire.py` 的内容

任务注册已在 `task_16dof.py` 的 `register()` 里加好。
